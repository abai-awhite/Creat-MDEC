## 崩溃原因
1. 版本 json 的 "jar" 字段仍写着旧名 Mechanomania-航空学，与实际 jar 文件名不一致，
   导致启动器/modu 系统多挂载一个名为 "Mechanomania" 的模块，与 "minecraft" 模块
   重复导出 com.mojang.blaze3d.systems → java.lang.module.ResolutionException 直接闪退。
2. 9 处依赖版本不匹配（详见日志 Missing or unsupported mandatory dependencies）。

## 第三轮（16:51 崩溃）
现象：能进到客户端 tick（1 tick 后崩），报
  java.lang.IllegalStateException: Cannot get config value before config is loaded.
  at com.girafi.minemenu.data.menu.RadialMenu.tickTimer(RadialMenu.java:30)
原因：MineMenu 1.14.3（1.21.1 最新版）自身的 bug —— 客户端 tick 在配置加载前读取配置值。
处理：移出 MineMenu-neoforge-1.21.1-1.14.3.jar（可选小工具，先保证能进游戏）。
备注：Modrinth/CurseForge 上 1.21.1 只有 1.14.2 / 1.14.3，暂无修复版；以后可换替代品。


## 第四轮（16:54 崩溃，TACZ）
现象：同一个 「Cannot get config value before config is loaded」，这次来自 tacz：
  com.tacz.guns.client.input.CrawlKey.onCrawlHoldingInput(CrawlKey.java:51)

根因（关键）：本实例的 config\modernfix-mixins.properties（从航空学继承）里有用户覆盖：
  mixin.bugfix.fix_config_crashes=false
这个 ModernFix bugfix 就是专门防止「mod 在配置加载前读取配置值」导致崩溃的。
它被关掉后，任何有这种毛病的 mod 都会在第一个客户端 tick 崩 —— MineMenu 先中招，TACZ 是第二个。

处理：把 mixin.bugfix.fix_config_crashes 改回 true（不动其他覆盖项）。
说明：不需要删 TACZ；MineMenu 之前已移出（那个 mod 自身问题更严重，保留也可以留着以后观察）。


## 第五轮（16:58 崩溃，仍是 TACZ）

## 第六轮（17:0x 复盘，找到真正根因）
之前 5 次崩溃全部是同一个根因链，不是 TACZ / MineMenu 自身的问题：

1. mod 构造阶段有 3 个 mod 失败：
   - powerfuljs 2.4.0：mixin 直接打穿 Create 6.0.10
     （SpoutMixin 引用 com.simibubi.create.foundation.fluid.FluidIngredient，这个类在 6.0.10 已不存在）
     同时 farmers_delight.StoveMixin 的 @Shadow INVENTORY_SLOT_COUNT 在 FD 1.3.4 里也没有
   - youkaishomecoming 3.0.8：NoSuchFieldError，FD 1.3.4 的 ModTags 里没有 CABBAGE_ROLL_INGREDIENTS
   - create 6.0.10：被 powerfuljs 的 mixin 错误连带炸掉，构造失败
2. NeoForge 打出 "Failed to wait for future Mod Construction, 3 errors found" → 进入 broken mod state
3. 之后所有事件（包括 ModConfigEvent.Loading 配置加载）都被 "Cowardly refusing to send event ... to a broken mod state" 拒绝
4. 结果：所有 mod 的配置都没加载，第一个在 client tick 里读配置的 mod 就崩——先 MineMenu、后 TACZ，都是症状，不是病因。

处理：
- 移出 powerfuljs（我们是从 CDR 移植池加的，航空学原包没有，不影响 KubeJS 主体）
- 移出 youkaishomecoming（同样后加的，与 FD 1.3.4 不兼容）
- TACZ 装回（枪械必须保留）
- 航空学原包的 FarmersDelight-1.21.1-1.3.4 本来就是基座，不动

## 第十五轮（11-25 启动即崩：mixin 配置带 BOM）
- 现象：PCLCE 提示「Minecraft 出现错误 / 无法确定原因」，游戏进程返回 1；
  latest.log 停在 mixin 初始化阶段，无 crash-report、无 Java 异常记录。
- 真因（从 PCL 启动日志的 RawOutput 中抓到）：
  Exception in thread "main"
  org.spongepowered.asm.launch.MixinInitialisationError:
    Error initialising mixin config futurevillagertradesvisible.mixins.json
  Caused by: IllegalArgumentException: The specified resource
    'futurevillagertradesvisible.mixins.json' was invalid or could not be read
  Caused by: JsonSyntaxException: Expected BEGIN_OBJECT but was STRING at line 1 column 1
- 验证：该 jar 内 futurevillagertradesvisible.mixins.json 开头有 UTF-8 BOM（EF BB BF），
  mixin 的 Gson 解析器把 BOM 当字符串开头 → 直接崩。
  全量扫描 305 个 jar 的 mixins.json / mods.toml，只有这一个文件带 BOM。
- 处理：备份原 jar 到 _work\jar-repairs\futurevillagertradesvisible-0.1.0.jar.orig，
  去掉 BOM 后重建 jar（27 条目原样保留），JDK jar 工具校验通过、JSON 解析通过。
- 备注：以后遇到「启动瞬间退出、无崩溃报告」，先看 PCL 的 Launch 日志 RawOutput，
  再看各 mod 的 mixins.json 是否有 BOM / 非法 JSON。
